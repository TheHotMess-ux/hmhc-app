# The Hot Mess Hormone Club App

## Purpose

A bold, supportive hormone-health companion combining cycle tracking,
perimenopause education, mood and symptom tracking, supplement tracking,
sleep support, nutrition guidance, pep talks, and doctor-ready reports.

## Main Navigation

1. Home
2. Track
3. Insights
4. Library
5. Profile

## Modules

### Home
- Daily hormone briefing
- Current cycle or hormonal phase
- Quick-log actions
- Daily pep talk
- Module shortcuts

### Track
- Mood Ring
- Cycle tracker
- Mood tracker
- Symptom tracker
- Supplement tracker
- Sleep tracker

### Insights
- Symptom patterns
- Mood trends
- Cycle trends
- Supplement consistency
- Doctor-ready reports

### Library
- The Hot Flash
- Feed the Fire
- Sleep, Babe
- Nervous system tools

### Profile

- Notification preferences

- Privacy and data controls
- Account settings
